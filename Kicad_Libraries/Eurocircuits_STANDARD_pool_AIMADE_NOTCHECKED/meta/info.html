Eurocircuits STANDARD pool – pooling profile (KiCad 10.0)

Unofficial manufacturing profile built from Eurocircuits' published STANDARD pool specifications and design guidelines (checked 2026-10-12). Not produced or endorsed by Eurocircuits.

Configuration: 2 layers, FR-4, 1.55 mm nominal, 18 µm base copper (≈35 µm final), routed edges, green/blue/black/red (DI) soldermask, white legend.

Hard limits (DRC errors), KiCad finished-hole values: track/gap 0.10 mm, PTH hole 0.10 mm, NPTH hole 0.20 mm, annular ring 0.15 mm (via ≥ 0.40 mm), hole-to-hole 0.25/0.30/0.35 mm (NPTH-NPTH / with PTH / PTH-PTH), copper-to-hole 0.20/0.25 mm, copper-to-edge 0.25 mm, slot width 0.50 mm.

Defaults (recommendations): Default net class 0.20 mm track / 0.15 mm clearance, via 0.70/0.30 mm.

Files: .kicad_pro (constraints, net class, presets), .kicad_pcb (stackup, mask, plot settings), .kicad_dru (custom rules incl. optional multilayer / V-cut / castellated blocks), .kicad_jobset (Gerber X2 + job file + Excellon drill zip). See README.md in the download.

Always re-check in the Eurocircuits configurator and PCB Checker before ordering.
